# NMAO — Season Champion Medallions (S1–S10)

*The flagship "perfect-season champion" medallion, one per season, each tinted by that
year's **Gem Series** color (the same color as that season's yin-yang Imprint medal).
Wording changed from an edition count to a **season number**: banner reads
**"SEASON CHAMPION"** with a small **S# tab** on the side.*

Base: the NMAO dragon coiled into a radiant medallion, **solid gold field**, **ornate
platinum + black-nickel frame** with an inset gem — only the **dragon's scale color and
the frame gem** change per season.

---

## On the text ("SEASON CHAMPION" + "S#")

Image models render baked-in words unreliably at this size. Two options:

- **Option A (recommended): generate text-free, composite type in post.** Use the
  "text-free" prompt variant below; I'll overlay crisp "SEASON CHAMPION" + "S#" in real
  type (consistent font, perfectly legible, identical placement across all ten). This is
  the cleanest and keeps the set uniform.
- **Option B: bake it in.** Use the "with text" prompt; expect to reroll a few times to
  get clean letters, and accept minor variation season to season.

## After you generate

Drop the 10 into `docs/badge-art/reference/` (name them `season-champion-s1.png` …
`s10.png`). Then the finishing is automated:
`python3 scripts/crop_medallion.py` → transparent medallions, then
`python3 scripts/letter_champion.py <in.png> <season#> <out.png>` bakes the crisp
**"SEASON CHAMPION"** banner + **S#** gold end-cap seal (proven working; identical
placement/type on all ten). Font is currently DejaVu Serif Bold as a stand-in — we can
swap to a premium engraved face (e.g. Cinzel / Trajan) for the finals. These pair with
the Gem Series badges (45–54) as the flagship, color-matched collectible line.
